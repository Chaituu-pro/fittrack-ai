# FitTrack AI

AI-assisted fitness tracking web application built with a production-ready full-stack architecture.

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB
- Auth: JWT
- Charts: Recharts
- Deployment: Vercel + Render

## AI Usage
AI is used only for classification and suggestions. All calorie calculations use standard MET formulas and verified food databases.
